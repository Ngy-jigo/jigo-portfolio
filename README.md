# Jigo Ngozi Ogbonnaya — Cloud & DevOps Portfolio

A professional, responsive portfolio built with plain HTML, CSS and JavaScript.

## Features
- Modern Cloud/DevOps visual identity
- Responsive mobile navigation
- Scroll progress indicator
- Animated reveal-on-scroll sections
- Project showcase with GitHub/live links
- Professional profile image
- About, skills, projects, journey, experience, credentials and contact sections
- No framework or build step required

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html` with your professional email.
2. Add your LinkedIn URL to the navigation/footer if desired.
3. Optionally add a `cv.pdf` file and a Resume button.
4. Review all dates and wording.

## Run locally
Open `index.html` directly in a browser, or use VS Code Live Server.

## Deploy
The easiest free option is GitHub Pages:
Repository → Settings → Pages → Deploy from branch → `main` → `/root`.
